# Property inspection & defect identification

*Roster skill S09. Used by: `due-diligence-specialist` (owner), `renovation-project-manager`, `property-manager`. Market facts are a Nov 2026 snapshot from `docs/`; refresh before relying on them.*

## Purpose
Catch expensive hidden problems and turn them into repair budgets and negotiating points.

## Checklist by system
| System | What to look for | Typical action/cost driver |
|---|---|---|
| Roof | Age (insurance hits at ≥ 15 yrs), shingle/tile condition, leaks, deck | Replace $18K–$36K (impact-rated higher) |
| Drains | **Cast-iron** (pre-1975) cracks, scale | Camera **sewer scope**; lining or replacement $8K–$25K+ |
| Supply pipes | Galvanized, polybutylene (1978–95) | Re-pipe (PEX/CPVC) $6K–$15K; insurers may refuse |
| Electrical | FPE/Stab-Lok, Zinsco, Challenger panels; fuses; aluminum branch wiring | Panel $2.5K–$5K; rewire if needed |
| HVAC | Age > 12–15 yrs, R-22, ductwork mold | Replace $8K–$15K |
| Windows/doors | Non-impact, no shutters | Impact upgrade $20K–$45K |
| Drywall | **Chinese drywall** (2001–2008 builds): sulfur smell, black copper | Specialist test; major remediation |
| Paint | **Lead paint** in pre-1978 homes | Disclosure; RRP-certified crews |
| Moisture | Mold, stucco cracks, window leaks | Remediation + source fix |
| Pests | Termites (subterranean & drywood) | WDO report; tent/treat; bond |
| Structure | Settlement cracks, spalling concrete, rusted rebar | Engineer letter |
| Pool | Resurfacing, equipment, barrier code | $8K–$20K |
| Additions | Unpermitted enclosures, garage conversions | After-the-fact permit or removal |

## Procedure
1. Read the inspection, 4-point, wind-mit, WDO and sewer-scope reports (ask for any missing).
2. Classify each finding: safety, insurability, lender, cosmetic.
3. Estimate cost ranges; pass them to `rehab-scoping-cost-estimating` and the negotiators.
4. List what still needs a specialist (engineer, mold, roofing, electrical).

## Output
A defect table (item, severity, insurability impact, cost range, action) and a short negotiation summary.
