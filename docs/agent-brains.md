# Agent Brains & Personalities

Each agent's model (its "brain") is set by the `model:` field in `.claude/agents/<agent>.md`. Each agent also has a first name, a voice and a working style in its **Your personality** section, and reads its own `knowledge/<agent>/` folder before every answer.

## How models were chosen
| Model | Used for | Agents |
|---|---|---|
| `opus` | Deep strategy, legal and finance judgment: high-stakes decisions where errors are expensive | 10 |
| `sonnet` | Most specialist work: research, analysis, modeling, planning, writing | 15 |
| `haiku` | Fast, simple lookups and checklist work from fixed procedures | 2 |

Rules of thumb:
- **Opus** when the agent makes or shapes a decision that commits money or creates legal exposure (strategy, financing, CFO, tax, all legal roles, compliance), or when it coordinates or designs the team (orchestrator, team architect).
- **Sonnet** when the work follows strong frameworks in the agent's skills but still needs solid reasoning, tool use or good writing.
- **Haiku** when the task is mostly calendars, checklists, lists and picks from predefined options. Questions outside that scope are handed to a sonnet or opus expert.

## Changing a brain or personality
- Edit the `model:` line in the agent's file. Valid values are `opus`, `sonnet`, `haiku`, `inherit` or a full model ID. Then update this table.
- Upgrade a haiku agent to `sonnet` if its answers miss nuance. Downgrade an opus agent to `sonnet` to cut cost and latency on routine questions.
- One-off override: when the orchestrator delegates it can ask for a different model for a single call. Precedence order: per-call model, then the agent's `model:` field, then `CLAUDE_CODE_SUBAGENT_MODEL`, then the main session's model.
- Personalities change tone only. Accuracy rules, citations and licensed-sign-off guardrails always apply.
- Ask the `team-architect` (Quinn) to make these changes; it also runs the validator.

## Knowledge folders
Each agent has `knowledge/<agent-name>/README.md` describing which company documents belong there. Add the company's own files (buy box, term sheets, inspection reports, approved lease forms, campaign results) and the agent will read them before answering. Sensitive files go in `knowledge/<agent-name>/private/`, which is git-ignored.
